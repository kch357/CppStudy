[초기화 리스트, initializer list]
    Marine::Marine() : hp(50), coord_x(0), coord_y(0), damage(5), is_dead(false) {}
    : 여기서 ':' 이후에 오는 것들을 초기화 리스트라고 함.
    멤벼 변수들의 초기화 작업들을 대신해서 함.

    추가로 초기화 리스트를 활용하면
    Marine::Marine(int coord_x, int coord_y) : coord_x(coord_x), coord_y(coord_y), hp(50), damage(5), is_dead(false) {}

    이와 같이 coord_x(coord_x)의 형태를 사용해도, 괄호 안에는 인자를 우선으로 지칭하고 바깥쪽은 무조건 멤버 변수를 지칭해서 정상적으로 작동함.

    초기화 리스트를 사용하면 '생성과 초기화'를 동시에 하는 것임.
    사용하지 않으면 생성을 먼저하고 그 다음에 대입을 수행하게 됨.

    const int a;
    a = 3;

    int& ref;
    ref = c;

    이처럼 상수와 레퍼런스들은 생성과 동시에 초기화를 하지 않으면 오류가 나는데, 이를 초기화 리스트를 사용해서 초기화 시킬 수 있음.
