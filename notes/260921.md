[함수의 오버로딩 (Overloading)]
    : C++ 에서는 함수의 이름이 같아도 인자가 다르면 다른 함수라고 판단한다. 따라서 같은 이름의 함수를 다른 인자로 선언할 수 있다.

오버로딩 단계 :
    1. 자신과 타입이 정확히 일치하는 함수를 찾는다.
    2. 1단계가 안되는 경우 다음과 같은 형변환을 거쳐 일치하는 함수를 찾는다.
        char, unsigned char, short -> int
        unsigned short -> int (or unsigned int, 크기에 따라)
        float -> double
        enum -> int
    3. 2단계가 안되는 경우 좀 더 포괄적이 형변환으로 일치하는 함수를 찾는다.
        숫자 타입 -> 다른 숫자 타입 (ex. float -> int)
        enum -> 숫자 타입
        0 -> 포인터 타입 or 숫자 타입
        포인터 -> void 포인터
    4. 사용자가 직접 정의한 타입 변환을 통해 일치하는 함수를 찾는다.

모호성(Ambiguous) 오류 :
    오버로딩 단계가 지나도 일치하는 함수를 찾을 수 없거나 두개 이상이 일치할 경우 오류 발생.


[class 밖에서 함수 정의하는 법]

(클래스)   {
    public:
        void (함수이름)();
};

void (class 이름)::(함수이름)() {

}


[생성자(constructor)]
    :  생성한 객체를 생성 후 초기화하는 과정을 도와주는 장치

    class A {
        int a;
        int b;
        int c;

        public:
            A(int d, int e, int f) {
                a=d;
                b=e;
                c=f;
            }
    };

    int main() {
        A (이름)(1, 2, 3);  //생성과 동시에 a, b, c가 1, 2, 3으로 초기화
    }

[디폴트 생성자(Default constructor)]
    : 생성자를 정의하지 않고 (클래스) (이름); 만 해도 생성자가 호출됨. 이는 디폴트 생정자(Default Constructor).

    디폴트 생성자는 인자를 하나도 가지지 않은 생성자여서 컴파일러가 자동으로 추가해줌. (컴파일러가 자동으로 생성할 때는 아무 일도 하지 않기 때문에 쓰레기 값이 저장됨.)

[디폴트 생성자 정의 방법]
    class test {
        int a;
        int b;

        public:

            test() {
                a = 1;
                b = 2;
            }
    }

    int main() {
        (클래스) (이름) = test();   
    }

    명시적으로 디폴트 생성자 이용하기

    class Test {
        public:
            Test() = default; // 디폴트 생성자를 정의해라
    };

    생성자 역시 함수여서 오버로딩이 적용됨.
