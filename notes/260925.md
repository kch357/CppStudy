[소멸자, Destructor]
    : ~T //T는 클래스의 이름
    객체가 소멸될 때 자동으로 호출되는 함수

[디폴트 소멸자, Default destructor]
    : 있는데 사실 의미 없음

[복사 생성자, copy constructor]
    : T(const T& a); //T는 클래스의 이름
    다른 객체를 기반으로 새로운 객체를 초기화할 때 호출

[디폴트 복사 생성자, Default copy constructor]
    : 원본 객체의 변수 값들을 새로운 객체에 그대로 똑같이 복사

    얕은 복사(shallow copy)
        : 단순히 대입
    깊은 복사(deep copy)
        : 메모리를 새로 할당해서 내용을 복사

    디폴트 복사 생성자는 얕은 복사밖에 할 수 없기 때문에 포인터 멤버 변수가 있는 경우에는 값이 아닌 주소값만 복사해서 원본 객체와 동일한 메모리 공간을 가리킴.
        -> 이중 해제(Double free 오류), 값 변경시 둘다 바뀔 수 있음
